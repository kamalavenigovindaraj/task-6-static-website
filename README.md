# Task 6: Host a Static Website with GitHub Pages

## Objective
Deploy a static website using GitHub Pages.

## Project Description
This project demonstrates how to create and publish a simple static website using HTML and CSS.

## Technologies Used
- HTML5
- CSS3
- GitHub Pages

## Project Files
- index.html: Contains the website structure and styling.
- README.md: Contains the project documentation.

## Deployment Steps
1. Created a static website using HTML and CSS.
2. Created a GitHub repository.
3. Uploaded index.html to the main branch.
4. Enabled GitHub Pages from Settings.
5. Selected the main branch and root folder.
6. Opened the published website.
